# 主题 

相当一部分插件都是提供另一个风格的主题样式，QUIK起始页内置了一个简单的API。

像这样添加一个主题选项，当用户在设置选择了这个主题后，body就会添加mytheme这个className :

```javascript 
quik.custom.addTheme('mytheme','我的主题',{
    color:['#fff','#333'], // 推荐的背景颜色 [亮色背景色，暗色背景色] 当用户设置背景为跟随主题时应用
    type:"global"// 见下方
})
```
其中type分三种：`global`,`color`,`structure`，分别对应全局主题，颜色主题，结构主题。

全局主题则是从颜色到元素结构等全部重写，且不能与其他主题组合使用。若不写明type则默认为全局主题。

颜色主题则是只更改颜色，结构主题则是只更改元素结构。这两种主题可以组合使用，结构主题也可以同时应用多种。

然后就可以像这样自定义样式：
```css
body.mytheme ...{
    /*...*/
}
```

对于颜色主题，我们提供了如下方便的CSS变量，页面大部分颜色均读取此变量库，修改时只需修改变量即可：

    --theme-color-mild:#0af;

    --shadow-mild:var(--gray-4);

    /*部分地方专属颜色*/
    --btn-color:var(--gray-2);
    --btn-hover:var(--gray-3);
    --btn-active:var(--gray-1a);
    --btn-text-color:var(--gray-10);

可通过开发者工具等理解每种变量的应用。



主题颜色可以通过以下方式获取：
```javascript
quik.custom.getColor() // dark | light
```
